## 🏗️ Architecture Pattern (Every Build Follows This)

```
TRIGGER → TRANSFORM → DELIVER
   ↓         ↓          ↓
 (Form,   (Clean,   (Email, Slack,
  Sheet,   Score,    Sheet, Telegram,
  Email,   AI Draft,  Digest, Notion,
  Webhook,  RAG,      Calendar)
  Schedule) MCP)
```

**Design principles:**
1. Human-in-the-loop for final decisions (AI drafts, human approves)
2. Confidence gates — AI escalates when unsure, never guesses (MCP pattern)
3. RAG-lite for knowledge bases — Sheets/Notion + Gemini, no expensive vector DB for 50-200 Q&As
4. Fake/test data only in demos — no client data ever in public repos
5. Documented + Loom walkthrough so any team member can run it without me
6. Works on both Make.com and n8n — client chooses, I build in their preferred stack
7. API Orchestration — 5-6 APIs in one workflow — premium skill
